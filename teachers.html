Daftar Guru

Username guru menggunakan NIP/NI PPPK, atau ID Guru internal jika belum memiliki nomor. Akun belum otomatis aktif sebelum dibuat oleh Super Admin.

Buat Akun Guru Massal

Akun yang sudah dibuat tidak diubah. Sistem memproses maksimal 5 guru setiap batch. Password awal diambil dari Secret Supabase.

Tambah Guru

Untuk guru tanpa NIP, gunakan ID internal unik. Jangan membuat ID yang sama.

Mata Pelajaran SMA

Daftar 23 pilihan yang disepakati sekolah: mapel umum, pilihan, BK, kokurikuler, dan layanan lainnya.

Pembuatan Akun Guru

Keamanan: akun dibuat menggunakan Supabase Edge Function di server. Secret/service role key tidak boleh ada di HTML, JavaScript browser atau config.js.

Setelah Edge Function dipasang, tombol Buat Akun atau Reset Password aktif untuk Super Admin. Password sementara tampil satu kali untuk disampaikan secara pribadi kepada guru, dan tidak disimpan dalam tabel.
